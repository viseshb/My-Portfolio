# My Portfolio Website - Overview

This repository contains the open source version of my portfolio website.

## Instructions

The project uses GSAP Club plugins. For production hosting, follow the official installation guidance: https://gsap.com/docs/v3/Installation/

**Tech stack** - React, TypeScript, GSAP, Three.js, React Three Fiber, WebGL, HTML, CSS, JavaScript

Visit the live portfolio at [viseshbentula.com](https://viseshbentula.com).
